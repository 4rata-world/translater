# Karisuke

Discordサーバー内のチャンネルをつないで、メッセージを各チャンネルの言語に自動で翻訳して届けるBotです。ロールパネルや認証ボタンなど、サーバー運営の機能も入っています。

- 翻訳には DeepL を使います
- 転送はWebhookで行うので、名前とアイコンは送った人のままです
- つながるのは、同じサーバーの中のチャンネルだけです

## できること

### 翻訳チャット

- 登録したチャンネルのメッセージを、他のチャンネルの言語に翻訳して転送
- 元のメッセージを編集・削除すると、転送先も連動
- 返信の引用つき（引用も翻訳されます）
- スラング辞書（DeepLの用語集）で、決まった訳し方を登録
- 転送の一時停止・再開、全チャンネルへの翻訳つきお知らせ
- 翻訳の上限に達したら、原文のまま転送して小さく注意書きを添える

### サーバー運営

- 埋め込みメッセージの送信
- ボタンでロールを付け外しするパネル
- 押すとロールが付く認証ボタン
- ようこそ・退出メッセージと自動ロール

## コマンド

| コマンド | できること | 必要な権限 |
|---|---|---|
| `/global-join` | このチャンネルをつなぐ（言語を選ぶ） | チャンネルの管理 |
| `/global-leave` | このチャンネルの接続を解除 | チャンネルの管理 |
| `/global-language` | このチャンネルの言語を変える | チャンネルの管理 |
| `/global-list` | つながっているチャンネルの一覧 | なし |
| `/global-pause` | 転送の一時停止・再開 | チャンネルの管理 |
| `/global-announce` | 全チャンネルに翻訳つきでお知らせ | サーバーの管理 |
| `/global-slang` | 決まった訳し方の登録・削除・一覧 | サーバーの管理 |
| `/global-ban` | 転送しないユーザーの管理 | メンバーをBAN |
| `/global-stats` | 翻訳の使用量（Botの持ち主のみ） | Botの持ち主 |
| `/embed` | 埋め込みメッセージを送る | メッセージの管理 |
| `/rolepanel` | ロールパネルを作る | ロールの管理 |
| `/verify` | 認証ボタンを作る | ロールの管理 |
| `/welcome` | ようこそメッセージの設定 | サーバーの管理 |
| `/help` | 使い方の一覧 | なし |

## 対応言語

日本語 / 英語 / 韓国語 / 中国語（簡体字）/ スペイン語 / フランス語 / ドイツ語 / ポルトガル語 / ロシア語 / イタリア語 / インドネシア語 / トルコ語 / アラビア語

スラング辞書は、インドネシア語・トルコ語・アラビア語には使えません。

## セットアップ

### 1. Discordでアプリを作る

1. [Discord Developer Portal](https://discord.com/developers/applications) で New Application
2. **Bot** タブで Token を取得
3. 同じ **Bot** タブで、次の2つをオンにする
   - Message Content Intent
   - Server Members Intent
4. **General Information** の Application ID を控える

### 2. 必要なキー

| 名前 | 中身 |
|---|---|
| `DISCORD_TOKEN` | Botのトークン |
| `CLIENT_ID` | Application ID |
| `DEEPL_API_KEY` | DeepL APIのキー（無料で取れます） |

`.env` に次の形で書きます。`=` の前後に空白や引用符は付けません。

```
DISCORD_TOKEN=
CLIENT_ID=
DEEPL_API_KEY=
```

**`.env` にトークンを書いたまま、GitHubに公開しないでください。** 公開リポジトリに載せたら、すぐに Token を Reset してください。ホスティング先に環境変数の欄があれば、そちらを使うのが安全です。

### 3. 起動する

```
npm install
npm start
```

起動すると、スラッシュコマンドは自動で登録されます（反映まで少し時間がかかることがあります）。

### 4. サーバーに招待する

招待リンクの `CLIENT_ID` の部分を自分のIDに変えて使います。

```
https://discord.com/oauth2/authorize?client_id=CLIENT_ID&permissions=805391360&scope=bot%20applications.commands
```

ロールを配る機能を使うには、サーバー設定の「ロール」で、Botのロールを、配りたいロールより上に動かしてください。管理者など強い権限を持つロールは、安全のため配れません。

## 使い方

1. つなぎたいチャンネルごとに `/global-join` を実行して、言語を選ぶ
2. 登録したチャンネルのどこかで話す
3. 他のチャンネルに、そのチャンネルの言語で届く

## ファイル構成

```
src/
├── index.js            Bot本体（転送・編集・削除の連動）
├── registry.js         チャンネル登録とBANのデータ
├── glossary.js         スラング辞書（DeepLの用語集）
├── config.js           サーバーごとの設定
├── deploy-commands.js  コマンドの手動登録（普通は不要）
├── commands/           スラッシュコマンド
└── features/           ボタンの処理、ようこそメッセージなど
data/                   自動で作られる保存先（登録データ）
```

## 運用のメモ

- 登録データは `data/` に保存されます。ホスティング先でファイルが消える環境だと、再デプロイのたびに `/global-join` のやり直しになります。永続する保存領域（Volume）があれば、`data/` に割り当ててください
- GitHubから同期し直すときは、`data/` を消さない方式（Merge）にしてください
- 翻訳の量は DeepL の無料枠（月50万文字）が上限です。`/global-stats` で確認できます
- 元のメッセージのIDは、Botの再起動で忘れます。再起動前のメッセージは、編集・削除しても転送先は変わりません

## 注意

- 転送するメッセージの本文は、翻訳のために DeepL に送られます
- Botが付けられるのは、Botのロールより下のロールだけです
